# PDF 轉 Word v0.1.1

維護版本，適用於 Windows x64。重點是修正輸出檔可能覆寫既有 Word 文件的問題，並更新 PDFium 與數個相依套件。建議所有 v0.1.0 使用者更新。

## 下載與使用

- `pdfword-0.1.1-portable-x64.zip`：解壓後執行 `pdfword.exe`，請保留同資料夾的 `pdfium.dll` 及授權文件。
- `pdfword-0.1.1-x64.msi`：全機安裝版，需要系統管理員權限。已安裝 v0.1.0 時會直接升級，不需先解除安裝。
- `SHA256SUMS.txt`：上述兩個附件的 SHA-256。PowerShell 可使用 `Get-FileHash <下載檔案> -Algorithm SHA256` 核對。

執行檔採靜態 CRT，不需另外安裝 VC++ 執行階段。程式及 MSI 均未數位簽章，Windows 可能顯示未知發行者或 SmartScreen 提示。

## 修正項目

### 最重要：輸出檔不再覆寫既有的 Word 文件

v0.1.0 在下列情況可能直接取代資料夾中原有的 DOCX：

- 選擇「略過」時，同一批有兩個同名 PDF（例如不同資料夾的 `報告.pdf`）輸出到同一個資料夾，而且 `報告 (1).docx` 已經存在，第二個檔案會寫到這個既有檔上。
- 轉換期間，另一個程式或另一個視窗先建立了同名檔。

v0.1.1 的處理方式：

- 加序號的名稱「檔名 (n).docx」在所有模式下都會避開已存在的檔案，以及同一批次已分配的名稱。
- 轉換結果先寫到同資料夾的暫存檔，完成後以「目標已存在就失敗」的方式落檔，不會取代既有檔案。
- 落檔時才發現撞名：「略過」模式會略過，「自動加序號」模式會改用下一個序號。
- 只有使用者明確選擇「覆寫」時，才會取代原始檔名的既有檔案；同一批次為避開重名而加序號的檔案，即使在覆寫模式下也不會取代既有檔。
- 轉換失敗、取消或略過時，不會留下暫存檔。

### 其他修正

- **嵌入圖片的方向與透明度**：PDF 中旋轉 90°／180°／270°、水平或垂直鏡射的圖片，現在會以正確方向輸出；含透明遮罩（SMask、Mask、色鍵遮罩）的圖片會保留透明背景。
- **加入資料夾不再卡住視窗**：掃描改在背景進行，掃描中會顯示已檢查的資料夾數與找到的 PDF 數，並可按「取消掃描」中止。無法讀取的項目與超過 16 層的子資料夾會計數並顯示「已略過 N 個」，不再靜默略過。掃描期間會停用加入、移除、清除與開始轉換。
- **「開啟輸出資料夾」開啟實際位置**：改為開啟這次轉換實際寫出檔案的資料夾，並在檔案總管中選取該檔；轉換後即使變更輸出資料夾設定，也不會開錯位置。

## 已知事項

- **zip 套件公告**：RUSTSEC-2026-0367、0368、0369、0429 針對 zip 8.6.0 的解壓縮功能，修補版本為 9.0.0；但 docx-rs 0.4.22（目前最新版）要求 zip 8.x，尚無相容的修補版。本程式只用 zip 產生 DOCX，原始碼中沒有任何讀取 DOCX 或解壓縮的呼叫，判斷不受這些公告影響。
- **任意角度的圖片**：旋轉角度不是 90° 倍數或有傾斜變形的圖片，會依原始外觀輸出為已轉好的點陣圖（外框以外為透明）。外觀正確，但在 Word 中無法再「轉回」原始方向編輯。
- 其餘限制與 v0.1.0 相同：採流式重排，不保證與原 PDF 完全一致；不含 OCR；密碼保護 PDF 無法轉換；PDF 整頁旋轉尚未處理。
- 解除安裝會保留使用者設定 `%APPDATA%\pdfword\settings.json`，重新安裝後沿用；如需完全清除，請手動刪除該資料夾。

## 驗證紀錄

在 Windows 11 x64（rustc 1.100.0）完成下列驗證：

- **自動測試**：47 個單元測試，以及 4 個整合／回歸測試（批次轉換、取消不留殘檔、公文回歸、圖片旋轉／鏡射／遮罩），在 PDFium 8125 下全部通過；`scripts\build.ps1` 打包時以 release 建置重跑一次，結果相同。
  - 防覆寫：以暫存資料夾實際驗證三種撞名情境（同批兩個同名 PDF、`x (1).docx` 已存在、落檔前才出現同名檔）× 三種模式，確認既有檔內容不變、沒有殘留暫存檔。
  - 圖片：以手寫的小型 PDF 驗證直立、順時針 90°、水平鏡射與 SMask 透明遮罩；同一測試在 v0.1.0 的程式碼上會失敗。
- **實際轉換**：以 3 份實際文件轉換，原檔 SHA-256 前後一致；含密碼保護的文件正確顯示錯誤，其餘輸出的 DOCX 皆可正常解析。更換 PDFium 8125 前後，同一份文件的轉換結果字數與圖片數相同。
- **介面**：掃描含數千個資料夾的大型目錄時，視窗持續回應、進度正常更新，取消後狀態正確恢復。
- **安裝程式**：
  - 從 v0.1.0 升級安裝為 v0.1.1：成功，舊版由安裝程式自動移除。
  - 以 `msiexec /x` 解除安裝：程式資料夾、開始功能表捷徑、解除安裝項目及 `HKCU\Software\pdfword` 均已移除，使用者設定保留。
  - 重新安裝：24 個負載檔案、捷徑均恢復，原設定（輸出資料夾、同名檔處理、同時轉換數）沿用；以安裝版轉換公文表單成功。
- **未驗證**：本版未以 Word 開啟輸出檔做版面比對（改以 MarkItDown 解析確認內容），檔案總管手動拖放仍無人工驗收紀錄。
